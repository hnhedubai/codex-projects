# H2 Projects

Project-owned pipeline for source-backed Hydrogen, Ammonia and other gaseous projects seeking partners.

This module is intentionally separate from `h2-dev`. `h2-dev` contains developer and capital-partner routes for the HydroH2 expansion; this module contains project records. A project is added only when its identity, sponsor/developer, geography, partnership signal and source evidence are available. No project or openness is inferred from a company-level lead.

Each record can later carry project-scoped contacts, sources, evidence, research history and outreach workflow through the shared Wind Projects detail layout.
