# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues at `hnhedubai/codex-projects`. Use the `gh` CLI for issue operations.

## Conventions

- Create specs and tickets as GitHub Issues.
- Read the issue, body, comments, and labels before implementation.
- Apply `ready-for-agent` only after the issue is fully specified.
- Pull requests are not a triage surface for this repository.
